# Educational ML Visualizer Research

## 1. Tool Comparison

| Tool | Best Feature | Known Weakness | How It Teaches |
| :--- | :--- | :--- | :--- |
| [TensorFlow Playground](https://playground.tensorflow.org/) | Live-training 2D decision boundary paired with real-time train/test loss curves and weight-colored network edges. | Hidden output-node bias confuses learners hand-checking math ([Issue #90](https://github.com/tensorflow/playground/issues/90)); hovered weights do not live-update during training ([Issue #198](https://github.com/tensorflow/playground/issues/198)); no guided explanation of why parameters succeed or fail ([Issue #195](https://github.com/tensorflow/playground/issues/195)). | Direct manipulation of architecture and features with immediate visual feedback. |
| [CNN Explainer](https://poloclub.github.io/cnn-explainer/) | Linked hover/click drill-down from layer feature maps to the underlying convolution, ReLU, and softmax math. | Hard-coded to a single pre-trained Tiny-VGG model; learners cannot swap datasets or add layers without editing source code ([Issue #34](https://github.com/poloclub/cnn-explainer/issues/34)). | Progressive disclosure: high-level overview first, exact math on demand. |
| [Transformer Explainer](https://poloclub.github.io/transformer-explainer/) | Connects live text input to attention heads, MLP blocks, and next-token probabilities in one continuous flow ([CHI '26](https://arxiv.org/html/2408.04619v2)). | Inference-only on a fixed GPT-2 model; learners cannot observe training dynamics or compare against other architectures. | Multi-abstraction linking from inputs through internal attention to output probabilities. |
| [Seeing Theory](https://seeing-theory.brown.edu/) | Calm editorial layout pairing one focused interactive canvas per concept with concise plain-language intuition ([GitHub](https://github.com/seeingtheory/Seeing-Theory)). | Covers probability/statistics rather than ML models; users on Reddit noted slow loading on mobile connections ([r/InternetIsBeautiful](https://www.reddit.com/r/InternetIsBeautiful/comments/5wpzjq/seeing_theory_a_visual_introduction_to/)). | Guided visual storytelling with minimal UI clutter. |
| [VisuAlgo](https://visualgo.net/) | Step-through execution synchronized with highlighted pseudocode and shareable URL state. | Focused on classical data structures and algorithms rather than ML; HN commenters noted dense UI and non-uniform English phrasing ([HN](https://news.ycombinator.com/item?id=14609321)). | Active step-by-step tracing paired with state transitions. |
| [Algorithm Visualizer](https://algorithm-visualizer.org/) | Synchronizes code execution with visual array and graph state. | Requires manual tracer annotations to visualize custom code; no ML algorithms ([Expora](https://tryexpora.com/blog/best-algorithm-visualizer-coding-interviews)). | Code-to-visual trace synchronization. |
| [ML Playground](https://ml-playground.com/) | Codeless 2D canvas for testing classic classifiers (KNN, SVM, Decision Tree, NN) on user-drawn points ([SaaSHub](https://www.saashub.com/compare-machine-learning-playground-vs-ml-visualization-ide)). | Shows only one algorithm at a time, lacks live training loss curves, and does not explain internal step math. | Rapid point plotting and boundary inspection. |
| [Teachable Machine](https://teachablemachine.withgoogle.com/) | Zero-code webcam/audio/pose training that makes "AI learns from examples" obvious in minutes. | Total black box where learners cannot inspect how decisions are made ([MDPI 2024](https://www.mdpi.com/2227-7102/14/4/417)); does not warn about class imbalance pitfalls ([Review](https://www.kidsaitools.com/en/articles/teachable-machine-review-2026)). | Fast example-driven experimentation. |

## 2. Borrowed Feature & Adaptation

- **Borrowed feature**: Live-training decision boundary paired with a real-time loss/metric curve (from [TensorFlow Playground](https://playground.tensorflow.org/)) plus on-demand probe math inspection (inspired by [CNN Explainer](https://poloclub.github.io/cnn-explainer/)).
- **Adaptation**: Instead of limiting the live curve to a neural network, we render a live, flat SVG loss/metric history chart across all iterative and staged algorithms (Linear Regression GD MSE, Logistic Regression log-loss, Neural Network cross-entropy, Linear SVM hinge/margin proxy, K-Means inertia, and Gradient Boosting stage-by-stage log-loss), and show exact probe predictions (class probabilities or neighbor votes) when testing a point.

## 3. Novel Feature & Gap Verification

- **Evaluated candidates**:
  - *"Break it" mode*: Already exists in [Gradient Descent — ML Visualization](https://www.mlvisualization.com/visualizations/gradient-descent), which includes a dedicated "Now Break It" learning-rate divergence exercise.
  - *Scrubbable timeline*: Step forward/backward playback already exists in [LEARN ALGO](https://www.learn-algo.com/) for DSA/ML algorithms.
  - *"Why did this step happen" debug mode*: [LEARN ALGO](https://www.learn-algo.com/) includes a debug mode explaining why each decision is made.
  - **Side-by-Side Algorithm Duel with Synchronized Step-Through**: Searches across educational ML visualizers found side-by-side comparison only in 3D TensorBoard point-cloud runs ([Open3D](https://www.open3d.org/html/tutorial/visualization/tensorboard_plugin.html)), medical MRI correlation tools ([GRACE](https://pmc.ncbi.nlm.nih.gov/articles/PMC4423600/)), and dynamic programming recursion vs. tabulation ([DP Visualizer](https://www.scribd.com/document/1067528311/Dynamic-Programming-Visualizer)). None of the studied 2D ML visualizers (TensorFlow Playground, ML Playground, Seeing Theory, Teachable Machine) let a learner run two different ML algorithms side-by-side on the exact same seeded dataset with synchronized `Step` / `Train` / `Reset` controls and a live accuracy/metric comparison.
- **Why it helps learners**: Beginners struggle to build intuition for *inductive bias*—for example, why Logistic Regression fails on XOR while a Decision Tree or MLP succeeds, or why Random Forest smooths Decision Tree axis splits. Synchronized Duel Mode makes that contrast visible in real time on identical data.
